## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
There is no seal-this-column-value entry point. Every embedder hand-wires Arc<Ciphers>, Arc<dyn KeySource>, CellContext and the transform choice — which is precisely where the silent failures in TASK-0192.01 and TASK-0192.03 happen. Ease of reuse is the whole point of the library, and this is the task that delivers it.

Build a Protector over the core policy model, with roughly:

    let p = Protector::new(policy, keys)?;
    let stored = p.seal("public.users.ssn", b"123-45-6789", Some(&row))?;
    let value  = p.open("public.users.ssn", &stored, Some(&row))?;
    let term   = p.search_term("public.users.email", b"a@b.io")?;
    let shown  = p.mask("public.users.ssn", &value);

Requirements: an unknown column name is an error, never a silent passthrough; a column whose table declares a row key refuses a None row rather than quietly sealing cell-only; search_term returns None for a column that is not searchable so the caller cannot build a predicate that matches nothing; RowKey construction goes through the canonicalization from TASK-0192.01.

Ship examples/embedded.rs: a plain sqlx application against a real Postgres that inserts an encrypted, blind-indexed column, queries it by equality using search_term, reads it back decrypted and masked — with no proxy process running. Wire it into the e2e make target so it cannot rot.

Reference shapes worth copying are recorded in plans/COMPARISON.md (AWS Database Encryption SDK, CipherStash Protect).

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Passthrough semantics: FieldTransform::open returns Ok(None) for pre-migration plaintext (crates/core/src/transform.rs). That is right for the proxy under on_unprotected; for a library it must be an explicit policy. Protector::open should return an enum (Opened / Plaintext) or take a strict flag, never hand back plaintext silently.

The example written here is expected to be rewritten against the derive in TASK-0192.08; keep it small.

Landed on lib/policy-model. Protector in crates/core/src/protector.rs; Opened { Value, Unprotected } with into_value/into_bytes; new Error variants UnknownColumn, RowKeyRequired, RowKeyNotDeclared, NotReadable, Unprotected. Typed RowKey constructors in rowkey.rs (pulled forward from 0192.08). Example at crates/core/examples/embedded.rs, run by make e2e; round-trip test library_and_proxy_share_one_table in crates/proxy/tests/e2e.rs on port slot 8. make e2e green locally (8 tests + example).
